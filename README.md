# LG IR Magic Remote

Native Android remote control for LG webOS televisions using the handset's consumer IR emitter.

The application includes a full remote interface and a home-screen widget. It implements standard infrared functions exposed by LG television remotes. Magic Remote pointer, microphone, Bluetooth, and motion functions cannot be reproduced through infrared.

## Build

GitHub Actions builds a debug APK on every push to `main` and uploads it as the `LG-IR-Magic-Remote-APK` artifact.

The current verification branch exists solely to run and validate the Android APK build workflow.
